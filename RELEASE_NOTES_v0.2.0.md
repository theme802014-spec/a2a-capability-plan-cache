# Capability-aware Agent Plan Cache v0.2.0

This release turns the initial reference kernel into a reviewable public reference project.

## Included

- source-grounded demand signatures
- normalized Agent Card supply observations
- field-level Skill and Card diffs
- dependency-aware shadow impact analysis
- serializable `PlanCacheEntry`
- safe rebinding of cached plans to current request values
- JSON Schemas for demand, supply, and plan evidence
- synthetic three-step health/community example
- architecture, lifecycle, evaluation, and prior-art notes
- automated tests through GitHub Actions

## Scope

This release does not contain production adapters, user data, credentials, private Card content, or a claim of patent novelty. The analyzer reports review signals; it does not authorize production execution by itself.
