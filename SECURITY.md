# Security policy

This repository is a reference package and should not receive production credentials or personal data.

Do not open an issue containing:

- API keys, access tokens, passwords, or authorization headers
- health records or other personal information
- private Agent Cards or internal service URLs
- production SQLite databases, cache files, or logs

For a suspected security issue in the code, open a private report through the repository owner's GitHub contact method instead of publishing sensitive details in an issue. The project does not promise a production security SLA.
